FIMS 졸업신고 자동화 · Excel 최종판 설치 및 사용

[처음 한 번만 설치]
1. FIMS_졸업신고_엑셀자동화_최종.zip의 압축을 완전히 풉니다.
2. Chrome 주소창에 chrome://extensions 를 입력합니다.
3. 우측 상단의 개발자 모드를 켭니다.
4. 기존 FIMS 졸업신고/변동신고 자동화 확장프로그램이 있으면 제거합니다.
5. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
6. 압축을 푼 폴더 안의 'FIMS_졸업신고_엑셀자동화' 폴더를 선택합니다.
   - 선택한 폴더를 열었을 때 manifest.json이 바로 보여야 합니다.
7. 확장프로그램 카드에 버전 3.0.1이 표시되는지 확인합니다.

[매번 실행]
1. 함께 제공된 졸업신고_업무파일.xlsx를 엽니다.
2. '실행설정' 탭의 사유발생일, 신고구분, 신고내용을 입력합니다.
   - 신고내용에 [입력 필요]가 남아 있으면 실행되지 않습니다.
3. '졸업신고명단' 탭 5행부터 처리대상(Y 또는 빈칸), 성명, 학번을 입력하고 저장합니다.
4. Chrome의 FIMS 졸업신고 자동화 아이콘 → 실행 화면 열기를 누릅니다.
5. 엑셀 파일을 선택하고 '파일 검사'를 누릅니다.
6. FIMS ID와 비밀번호를 입력합니다.
7. '새 FIMS 창 → 로그인 → 명단 처리'를 누릅니다.
   - 이때 기존에 열려 있던 www.hikorea.go.kr 및 fims.hikorea.go.kr의 FIMS 탭·팝업은 자동으로 닫힙니다.
   - 새 Chrome 창 하나가 실제 FIMS 로그인 주소로 열립니다.
8. 새 창에서 로그인 → 좌측 변동신고 메뉴 → 학생별 조회·체크·보내기와 신고내용 일괄입력이 끝날 때까지 기다립니다.
9. 화면에 표시된 최종 대상자 수, 사유발생일, 신고구분, 신고내용과 FIMS 화면을 대조합니다.
10. 최종 확인란을 체크한 뒤 '최종 신고처리 실행'을 누릅니다.
11. 완료 건수를 확인한 뒤 '처리결과 엑셀 저장'을 눌러 결과 파일을 보관합니다.

[기존 FIMS 대기명단에 다른 학생이 있는 경우]
- 오류가 아닙니다.
- 확장프로그램은 대기명단 전체선택을 사용하지 않습니다.
- 기존 학생의 체크를 해제하고 이번 엑셀 명단의 성명·학번 정확 일치 행만 선택합니다.
- 엑셀 대상 학생이 이미 대기명단에 정확히 1건 있으면 다시 보내지 않고 그 행을 이번 작업에 포함합니다.
- 이번 대상과 동일한 성명·학번이 대기명단에 2건 이상이면 중복 위험 때문에 중단합니다.

[오류 학생 처리]
- 학생 정보가 없거나 성명·학번이 맞지 않으면 해당 학생만 '이름, 학번 불일치'로 기록하고 다음 학생을 계속합니다.
- 검색 직후 직전 학생의 빈 결과는 즉시 실패로 판정하지 않고 새 조회 결과를 기다립니다.
- 오류를 수정한 뒤 같은 엑셀을 다시 검사하고 실행하면 재조회할 수 있습니다.

[중요]
- Apps Script 코드, 웹앱 배포, URL, 연결 토큰은 모두 필요 없습니다.
- 실행 전에 보관할 내용이 있는 FIMS 화면이 있다면 먼저 저장하세요. 실행 버튼은 기존 FIMS 탭을 모두 닫고 새 전용 창을 만듭니다.
- 보내기·저장·최종 신고 확인창은 자동 확인되지만, 최종 신고 시작은 사용자가 확인란과 버튼으로 승인해야 합니다.
- 비밀번호는 엑셀이나 Chrome 저장소에 보관하지 않습니다.
- 실제 운영 전에는 먼저 샘플 1명으로 최종 신고 직전까지 확인하세요.
