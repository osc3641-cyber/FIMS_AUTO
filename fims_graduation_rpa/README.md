# FIMS 졸업신고 자동화 · Excel 최종판

Google Apps Script 없이 3개 탭 `.xlsx` 파일만 사용하는 Chrome Manifest V3 확장프로그램입니다.

## 처리 흐름

1. `졸업신고_업무파일.xlsx` 업로드 및 입력값 검사
2. 기존에 열려 있는 FIMS 탭·팝업을 모두 종료
3. 실제 로그인 주소 `https://fims.hikorea.go.kr/isi/MembIsiLogin.isi`를 새 Chrome 창 하나에서 열어 로그인
4. `leftFrame`의 실제 이동 링크 `#nMenuTreeHome16`을 클릭하고 `mainFrame` 검색 화면 대기
5. `mainFrame`에서 학생별 학번·성명 입력, 유사 체크, 조회
6. `chgIntlStudFrame`에서 체크박스 `title`의 성명과 같은 행 학번을 모두 확인
7. 정확히 한 건만 체크한 뒤 `mainFrame`의 보내기 실행
8. `notiListFrame`에서 이번 엑셀 대상만 골라 신고내용 일괄입력
9. 사용자 최종 확인 후 이번 엑셀 대상만 다시 선택하여 신고처리
10. 완료 알림 건수 검증 후 세 번째 `처리결과` 탭이 채워진 엑셀 다운로드

## 반영된 안전장치

- Apps Script 웹앱 URL, 연결 토큰, 권한 승인, 네트워크 기록 요청이 없습니다.
- 매 실행마다 기존 FIMS 탭과 팝업을 닫은 뒤 새 전용 Chrome 창에서 시작합니다.
- 좌측 메뉴의 상위 토글 `#nMenuTreeHome15`가 아니라 실제 변동신고 링크 `#nMenuTreeHome16`만 클릭합니다.
- 검색 직후 직전 학생의 빈 결과가 잠시 남아도 새 결과가 갱신될 때까지 기다립니다.
- 결과 체크박스의 `title` 성명과 같은 행의 학번이 모두 일치해야 선택합니다.
- 이미 FIMS 대기명단에 같은 성명·학번이 정확히 1건 있으면 중복 전송하지 않고 이번 엑셀 대상으로 인계합니다.
- FIMS 대기명단의 다른 학생은 오류로 보지 않으며 체크를 모두 해제한 뒤 이번 엑셀 대상만 선택합니다.
- 이번 대상이 누락됐거나 동일 성명·학번으로 중복된 경우 일괄입력과 최종 신고를 차단합니다.
- 보내기·일괄저장·최종신고의 확인창은 상위 프레임을 포함한 모든 FIMS 프레임에서 처리합니다.
- 학생별 오류가 나도 다음 학생을 계속 처리합니다.
- 최종 신고는 별도 확인란을 직접 체크해야 실행됩니다.
- 완료 알림 건수와 예상 건수가 같을 때만 `졸업신고 완료`로 기록합니다.
- 비밀번호는 파일이나 Chrome 저장소에 저장하지 않습니다.
