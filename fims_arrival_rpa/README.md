# FIMS 입국신고 자동화 · Excel판

Google Sheets·Apps Script 없이 `.xlsx` 명단을 직접 읽어 FIMS 유학생기본정보의 입국 관련 항목을 학생별로 수정하고 결과를 세 번째 탭에 기록하는 Chrome 확장프로그램입니다.

현재 버전: **1.0.7 (2026-09-11 조회 전용 진단 모드 추가)**

- 기존 FIMS 탭을 모두 닫고 `fims.hikorea.go.kr` 쿠키를 지운 뒤 확장프로그램 전용 팝업 창에서 공식 진입점 `index.html → bodyFrame/login.jsp`로 시작합니다.
- 로그인 화면을 2.5초 안정화하고 입력칸을 읽기 전용으로 잠가 브라우저 자동완성을 차단합니다. 기존 값을 지운 뒤 잠금을 푸는 순간 실행 화면의 ID·비밀번호를 다시 넣고 즉시 로그인 버튼을 클릭합니다.
- 수집된 실제 버튼 `input[name="Button2"][onclick*="membLogin"]`만 클릭합니다.
- Excel 성명의 반각·전각 쉼표를 공백으로 바꾸고 중복 공백을 정리한 뒤 FIMS 검색에 사용합니다.
- 로그인 후 `유학생현황/변동신고 반려처리 건수` 안내창이 실제로 나타난 경우에만 자동 확인하고, 나타나지 않으면 바로 메뉴로 진행합니다.
- `ID를 확인해주세요` 같은 로그인 오류 안내는 정상 안내와 분리해 실패 처리합니다.
- Chrome `debugger` 권한을 제거했습니다. 로그인과 저장 과정에서 “브라우저를 디버깅 중” 안내 막대가 뜨지 않습니다.
- 잘못된 계정 정보는 FIMS 경고 문구를 실행 로그에 표시하고 작업을 중단합니다.

## 처리 흐름

1. 기존 `www.hikorea.go.kr/isi/*`, `fims.hikorea.go.kr/*` 탭과 팝업 종료 및 FIMS 세션 쿠키 삭제
2. 확장프로그램 전용 팝업 창에서 FIMS 공식 진입점으로 접속 → 화면 안정화 → 입력칸 잠금 → 자동완성 값 제거 → 잠금 해제와 동시에 사용자 입력값 재입력 → 실제 로그인 버튼 클릭
3. 로그인 후 선택적 현황 안내창이 있으면 자동 확인, 없으면 그대로 진행
4. `유학생정보관리(#nMenuTreeHome6)` → `유학생기본정보(#nMenuTreeHome7)` 진입
5. 성명 `#sEkNm`, 생년월일 `#sBirthYmd` 입력 및 유사 `#sLikeYn` 체크
6. 수집 요소 `a[title="상세조회"]` 또는 `a[onclick*="fncGetDetail"]`로 학생 이름 링크 열기
7. 상세화면의 성명·생년월일을 엑셀과 재검증
8. `수정` → 학번 `#scholNo` 입력
9. 입국일자 콤보 `#entrYN`에서 실제 값 `N`(입국) 선택
10. 입학(복학)일자 `#admsnYmd` 입력
11. `a[onclick*="fncSave"]` 저장 및 확인·완료 대화상자 자동 승인
12. 저장 후 상세화면에서 `YYYY.MM.DD (입국)` 확인
13. 처리결과 엑셀 저장

## 안전 조건

- 성명은 FIMS 여권명 표시 한도인 앞 38자를 기준으로 비교합니다.
- Excel 성명의 쉼표(`,`, `，`)는 제거하고 공백으로 처리합니다. 예: `SAMPLE SURNAME, GIVEN MIDDLE` → `SAMPLE SURNAME GIVEN MIDDLE`.
- 검색과 상세화면에서 생년월일을 반드시 다시 확인합니다.
- 결과 이름이 화면에서 `SAMPLE SUR...`처럼 잘리거나 링크 글자가 비어 있어도 검색조건이 유지되고 상세조회 링크가 1건뿐이면 그 링크를 엽니다. 수정 전에 상세화면 성명·생년월일을 다시 검증하므로 다른 학생은 수정하지 않습니다.
- 같은 성명 결과가 2건 이상이면 수정하지 않고 `동일 학생 다중 조회`로 기록합니다.
- 수정화면에서도 성명·생년월일 확인 후에만 입력합니다.
- `#entrYN`은 화면 글자가 아니라 실제 옵션 값 `N`과 표시 글자 `입국`을 함께 검증합니다.
- 학번과 입학(복학)일자가 입력 후 유지되는지 확인하고 저장합니다.
- 저장 후 입국일자가 없으면 `입국일자 미확인`과 `별도 처리 필요`를 기록합니다.
- `#eYmd` 입국일자는 읽기 전용 확인값이므로 자동 입력하지 않고 저장 후 결과 확인에만 사용합니다.
- 학생별 오류가 발생해도 다음 학생으로 계속 진행합니다.
- FIMS ID·비밀번호는 파일과 Chrome 저장소에 보관하지 않습니다.

## 엑셀 구조

- `실행설정`: 업무구분, 입학(복학)일자
- `입국신고명단`: 처리대상, 성명, 생년월일, 학번, 비고
- `처리결과`: 성명, 생년월일, 학번, 처리결과, 확인된 입국일자, 비고, 상세메시지, 처리일시

자세한 설치·실행 순서는 `설치안내.txt`를 확인하세요.
